# EXPLORE

Discover more. Experience more.

個人化的探索網站：每天為你挑選值得認識的知識、嗜好和體驗，陪你走過「發現 → 了解 → 去做 → 回顧 → 再發現」。

- **今日**：依首次問卷（興趣、偏好看或做、每週時間、預算、一個人或朋友）與收藏／略過紀錄，每天推薦 4–5 張卡片，三類至少各一，附推薦理由。
- **探索**：30 個主題可篩選、搜尋、收藏、略過，「幫我抽三個新發現」從還沒看過的主題抽。
- **Deep Dive**：簡介、為什麼有趣、關鍵概念、冷知識、下一步、相關主題；嗜好類附入門裝備與新手常犯錯，體驗類附三步行動清單與台中地點。
- **Hobby Starter**：10 個嗜好各有七天新手挑戰，可打勾、寫每日筆記、完成後寫心得。
- **我的旅程**：統計、三類平衡、收藏、完成的挑戰與體驗、筆記、時間軸、備份。

所有內容事先寫好（`topics.js`），沒有呼叫任何 AI 或後端；資料只存在使用者瀏覽器。
