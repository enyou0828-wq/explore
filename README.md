# EXPLORE

Discover more. Experience more.

個人化的探索網站：每天為你挑選值得認識的知識、嗜好和體驗，陪你走過「發現 → 了解 → 去做 → 回顧 → 再發現」。

- **今日**：依首次問卷（興趣、偏好看或做、每週時間、預算、一個人或朋友）與收藏／略過紀錄，每天推薦 4–5 張卡片，三類至少各一，附推薦理由。
- **探索**：95 個主題可篩選、搜尋、收藏、略過，「幫我抽三個新發現」從還沒看過的主題抽。
- **Deep Dive**：簡介、為什麼有趣、關鍵概念、深入一點、冷知識、下一步、推薦讀物與實作、相關主題；嗜好類附入門裝備與新手常犯錯，體驗類附三步行動清單與台中地點。
- **讀完小測驗**：32 篇知識類主題各 3 題（`quiz.js`），答完馬上看解釋、不設門檻、可跳過，接著用自己的話講一次。
- **自己再挖深一點**：每個主題有維基百科／YouTube／Google（知識類加 Google 學術）搜尋入口，自學後可記一筆（類型、分鐘、學到什麼、連結），首頁「接著挖深」每天推一個已完成主題的下一步。
- **Hobby Starter**：20 個嗜好各有七天新手挑戰，可打勾、寫每日筆記、完成後寫心得。
- **我的旅程**：統計、技能樹（16 個興趣分枝從「你」放射，主題依興趣標籤出現在對應分枝、點數共用；點分枝中心放大；每個主題 7 點：看過 1、收藏 1、完成 3、自學紀錄 2）、我的學習紀錄（自學時數與紀錄）、收藏、完成的挑戰與體驗、筆記、時間軸、備份。

所有內容事先寫好（`topics.js`、`topics2.js`、`topics3.js`、`extra.js`、`quiz.js`，圖示在 `icons.js`），沒有呼叫任何 AI 或後端；資料存在使用者瀏覽器，選擇登入 Google 後同步到 Firestore（`cloud.js`）。
